# Cyber Admin v2

Next.js(App Router) + TypeScript 기반으로 구현한 v2 프로젝트입니다.

## 버전 안내

- **v1 (기존 SPA 버전)**

  - Tech: Vite + React + React Router + Redux Toolkit
  - 레포: https://github.com/eisont/cyber_csr

- **v2 (현재 레포)**
  - Tech: Next.js(App Router) + TypeScript
  - 이후 React Query, MSW, FSD 구조 등을 적용할 예정입니다.

## 개발

```bash
npm install
npm run dev
```
